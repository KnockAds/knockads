คู่มือใช้งาน Knock Ads แบบ Start to End

เอกสารนี้พาคุณตั้งแต่ยังไม่มีอะไรเลย จนถึงยิงแคมเปญแรกได้จริง พร้อมจุดที่คนส่วนใหญ่ติดขัดและวิธีแก้ไว้ครบ ทำตามทีละขั้นได้เลย

ทำตามทีละขั้น ไม่หลงทาง

ฟีเจอร์หลักของ Knock Ads ครบและใช้งานได้จริงทุกส่วน ส่วนที่ยากที่สุดในทั้งระบบคือขั้นตอน "เอา Token จาก Meta" ไม่ใช่ตัวแอปเอง คนส่วนใหญ่ที่เพิ่งเริ่มจะติดตรงเรื่อง permission ของ Meta — ถ้าทำตามลำดับในหัวข้อ "ขั้นตอนติดตั้ง" ด้านล่างทีละข้อโดยไม่ข้าม จะไม่เจอปัญหานั้น

อ่านก่อนเริ่ม

ระบบ "ปิดโฆษณาอัตโนมัติ" และ "รายงานรายสัปดาห์" ทำงานเฉพาะตอนที่เปิดแท็บเว็บนี้ค้างไว้เท่านั้น เพราะเป็นเว็บไฟล์เดียวไม่มีเซิร์ฟเวอร์เบื้องหลัง — ปิดแท็บหรือปิดคอมเมื่อไหร่ ระบบจะไม่ทำงานให้ (มีรายละเอียดในหัวข้อ "ข้อควรระวัง" ด้านล่าง)

เตรียมตัวก่อนเริ่ม

ต้องมีของ 4 อย่างนี้ก่อน ถึงจะเชื่อมแอปได้

1. บัญชี Facebook ส่วนตัว

ต้องเป็นแอดมินของเพจ และมีสิทธิ์เข้าถึงบัญชีโฆษณา (Ad Account) ที่จะใช้ยิงแอด — ถ้ายังไม่มีบัญชีโฆษณา ต้องสร้างใน Business Manager ก่อน

2. บัญชีโฆษณาที่ผูกบัตร/วิธีชำระเงินแล้ว

Knock Ads ไม่ได้สร้างบัญชีโฆษณาให้ — แค่ควบคุมบัญชีที่มีอยู่แล้ว ต้องตั้งวิธีชำระเงินใน Ads Manager ของ Meta ให้เรียบร้อยก่อน

3. ใจเย็น ๆ กับขั้นตอน Meta 10 นาทีแรก

ส่วนที่ยากที่สุดคือการเอา Token จาก Meta ไม่ใช่ตัวแอป — ทำตามลำดับในคู่มือนี้ทีละขั้น อย่าข้าม จะไม่มีปัญหา

4. เบราว์เซอร์เครื่องของตัวเอง

Token และ API Key ทุกตัวเก็บอยู่ในเบราว์เซอร์ของแต่ละคนเท่านั้น (ไม่มีระบบบัญชีผู้ใช้กลาง) ถ้าเปลี่ยนเครื่อง/เปลี่ยนเบราว์เซอร์ ต้องเชื่อมต่อใหม่

ขั้นตอนติดตั้ง (ทำครั้งเดียว)

เรียงตามลำดับที่ใช้แล้วลื่นที่สุด ทำตาม 1 → 9 ทีละข้อ อย่าข้าม โดยเฉพาะข้อ 4 และ 5

1

สร้างแอป Meta ของตัวเอง

ไปที่ developers.facebook.com → ล็อกอิน → My Apps → Create App → เลือกประเภท Business → ตั้งชื่ออะไรก็ได้ → สร้าง จากนั้นกด Add Product ในแดชบอร์ดแอป แล้วเพิ่ม Marketing API

2

เผยแพร่แอปทันที (Publish)

ทำต่อจากข้อ 1 เลย ไม่ต้องรอ — ไปที่ Settings → Basic แล้ววาง Privacy Policy URL ใช้ลิงก์สำเร็จรูปนี้ได้เลย ไม่ต้องทำเอง กดเปิดดูหรือกดคัดลอกไปวางได้ทันที:

Privacy Policy: knockads.github.io/knockads/privacy-policy.html
Data Deletion: knockads.github.io/knockads/data-deletion.html

ใส่ Privacy Policy URL เสร็จแล้วกดสวิตช์เผยแพร่แอป (Live) ที่มุมซ้ายบนของแดชบอร์ดแอปได้เลย ทำตั้งแต่ตอนนี้จะได้ไม่ต้องมากังวลเรื่องนี้อีกทีหลัง (ทำไมต้อง Publish เลยตั้งแต่ต้น ดูคำอธิบายในหัวข้อ "ปัญหาที่พบบ่อย" ด้านล่าง)

ไม่มีเว็บของตัวเอง? ทำฟรีด้วย Google Sites ใน 5 นาที

อยากได้ลิงก์ Privacy Policy เป็นของตัวเองแทนการใช้ลิงก์ Knock Ads ด้านบน ทำได้ฟรีโดยไม่ต้องมีโดเมน:

1. ไปที่ sites.google.com/new → เลือกแบบ "ว่างเปล่า" เพื่อเริ่มเว็บใหม่
2. คลิก "ใส่ชื่อเว็บไซต์" มุมซ้ายบน → ตั้งชื่อ เช่น "Privacy Policy - [ชื่อธุรกิจ]"
3. เปิดแผง Pages ด้านขวา → กดปุ่ม + ที่มุมล่างขวา → New page → ตั้งชื่อ "Privacy Policy" → Done
4. กด Insert → Text box แล้วพิมพ์เนื้อหานโยบายความเป็นส่วนตัวลงไป (เอาจากเว็บ Knock Ads ด้านบนมาปรับเป็นต้นแบบได้)
5. กด Publish มุมขวาบน → ตั้งที่อยู่เว็บ (URL) → กด Publish อีกครั้ง → ก๊อปลิงก์ที่ได้ไปวางในช่อง Privacy Policy URL

ไม่ต้องทำ "Domain Verification" (ยืนยันความเป็นเจ้าของโดเมน) ใด ๆ ทั้งสิ้น — ฟีเจอร์นั้นอยู่คนละส่วนกับการเผยแพร่แอป ข้ามได้เลยสำหรับ Knock Ads

3

สร้าง System User ใน Business Portfolio

นี่คือ "บัญชีหุ่นยนต์" ที่จะถือ Token แทนตัวเรา ไปที่ business.facebook.com/settings → เลือกพอร์ตโฟลิโอ (Business Portfolio) ของตัวเอง → เมนูซ้าย ผู้ใช้ → ใช้ระบบ (System Users) → กด เพิ่ม → ตั้งชื่ออะไรก็ได้ (เช่น "Knock Ads Bot") → เลือกบทบาท Admin → สร้าง

4

เพิ่มแอปเข้าพอร์ตโฟลิโอ แล้วให้สิทธิ์ System User เข้าถึงแอป

ยังอยู่ใน Business Settings → เมนูซ้าย บัญชี → แอป (Apps) → กด เพิ่ม (Add) → เลือก เชื่อมต่อรหัสแอป (Connect an app ID) → วาง App ID (ดูได้ที่ Settings → Basic ของแอปในข้อ 1) → กด เพิ่มแอป

คลิกเข้าไปที่แอปที่เพิ่งเพิ่ม → หาส่วนที่กำหนดคนที่มีสิทธิ์เข้าถึงแอป (People / Assign people) → เพิ่ม System User ที่สร้างไว้ในข้อ 3 เข้าไป → ให้สิทธิ์ระดับ Admin

ทำไมต้องเพิ่ม System User เข้าแอปด้วย

ขั้นนี้คือการให้สิทธิ์ระดับ "แอป" ว่าใครใช้แอปนี้ได้บ้าง — คนละเรื่องกับข้อ 5 ที่เป็นการให้สิทธิ์ระดับ "ทรัพย์สิน" ว่า System User เข้าเพจ/บัญชีโฆษณาไหนได้บ้าง ต้องทำให้ครบทั้งสองขั้น ไม่งั้น Generate Token ในข้อ 6 จะไม่เห็นแอปให้เลือก

5

เพิ่ม System User เข้าเพจและบัญชีโฆษณา

ยังอยู่ใน Business Settings → เมนูซ้าย บัญชี → เพจ (และ บัญชี → บัญชีโฆษณา) → เลือกเพจ/บัญชีที่จะใช้ → กด มอบหมายคน (Assign people) → เลือก System User ที่สร้างไว้ → ให้สิทธิ์ระดับ Admin หรือ ผู้ลงโฆษณา ขึ้นไป → ทำซ้ำทั้งฝั่งเพจและฝั่งบัญชีโฆษณา

ขั้นที่ลืมไม่ได้

ถ้าข้ามขั้นนี้ ต่อให้ Token มี permission ครบ ก็ยังจะเจอ error ว่าไม่มีสิทธิ์เข้าถึงบัญชีโฆษณา/เพจอยู่ดี

6

Generate Token จาก System User

เมนูซ้าย ผู้ใช้ → ใช้ระบบ (System Users) → เลือก System User ที่สร้างไว้ → กด Generate New Token → เลือกแอปที่สร้างในข้อ 1 → ติ๊ก permission ทั้งหมดนี้ให้ครบ (8 ตัว):

ads_readads_managementbusiness_managementcatalog_managementpages_manage_adspages_read_engagementpages_show_listthreads_business_basic
จุดที่พลาดกันบ่อยที่สุด

ตัวที่มักลืมคือ pages_show_list เพราะชื่อคล้าย pages_read_engagement แต่เป็นคนละตัวกันและทำหน้าที่ต่างกัน — pages_show_list คือตัวที่ Meta ใช้จริงสำหรับดึงรายชื่อเพจที่บริหารอยู่ ติ๊กทั้ง 8 ตัวไปพร้อมกันเลย ไม่ต้องเลือกว่าจะเอาตัวไหนออก

กด Generate Token → Token จะโชว์ให้เห็น ครั้งเดียว ก๊อปเก็บไว้ให้เรียบร้อยก่อนปิดหน้าต่าง — Token แบบนี้ไม่มีวันหมดอายุ ไม่ต้องมาต่ออายุทุก 60 วัน

มีทางลัดไหม เผื่ออยากทดสอบเร็ว ๆ ก่อน

มี — ไปที่ developers.facebook.com/tools/explorer เลือกแอปของเรา → Add Permissions ติ๊ก permission ชุดเดียวกับด้านบน → Generate Access Token ได้ Token ทันทีโดยไม่ต้องทำข้อ 3-5 เลย แต่ข้อเสียคือ Token แบบนี้หมดอายุทุก 60 วัน ต้องมาต่ออายุเองที่ developers.facebook.com/tools/debug/accesstoken เหมาะกับทดสอบเฉย ๆ ไม่เหมาะกับใช้งานจริงจัง

7

หา Ad Account ID

เปิด adsmanager.facebook.com → ดูที่ URL จะมี act=123456789 → ใช้เป็น act_123456789 (มี act_ นำหน้าเสมอ)

8

เชื่อมต่อในแอป Knock Ads

เปิด knockads.github.io/knockads → เมนู เครื่องมือ → Token → วาง Access Token และ Ad Account ID ในการ์ด META ACCESS TOKEN → กด บันทึก แล้วกด ทดสอบ Token

9

รันตรวจระบบก่อนใช้จริง

เมนู เครื่องมือ → ตรวจระบบ → กด รันตรวจทั้งหมด ระบบจะยิงทดสอบทุกจุดจริง (Token, บัญชีโฆษณา, สิทธิ์เข้าถึงเพจ, แคมเปญ ฯลฯ) ถ้าทุกแถวขึ้น ✅ แปลว่าพร้อมใช้งานเต็มรูปแบบ — ถ้ามีแถวไหนขึ้น ❌ ให้อ่านข้อความ error ในแถวนั้น มันบอกวิธีแก้ตรง ๆ

ใช้งานประจำวัน

แผนที่เมนูทั้งหมด — เปิดคู่กับแอปจริงแล้วไล่ตามได้เลย

ภาพรวม
แดชบอร์ดสรุป KPI หลัก, ยอดขาย, กราฟรายวัน — เลือกช่วงวันที่ได้เอง ไม่ใช่แค่ 7/30 วัน
จัดการโฆษณา
Ads Manager — Wizard สร้างแคมเปญใหม่ 4 ขั้น (Campaign → Targeting → Creative → Review) รองรับทั้งโฆษณาแบบเว็บไซต์และแบบข้อความ (Messenger/WhatsApp)
AI Ad Creator — เลือกแอดที่ทำผลงานดี ให้ AI ช่วยคิดก็อปปี้/รูปใหม่ แล้วโคลนเป็นแอดใหม่ได้ทันที
AI Drafts — ที่เก็บก็อปปี้ที่ AI คิดไว้ ยังไม่ได้ใช้งาน
วิเคราะห์
AI แนะนำ — สรุปจุดที่ควรปรับทั้งบัญชีในคลิกเดียว
A/B Testing, Sales Funnel, Audience Insights, คัดกรองลูกค้า, Creative Performance, Dayparting, Geo จังหวัด — วิเคราะห์เจาะแต่ละมุม พร้อมคำแนะนำจาก AI ทุกหน้า
อัตโนมัติ
ตั้งกฎปิดโฆษณาอัตโนมัติ, ตรวจตามเวลาที่กำหนด, รายงานสรุปรายสัปดาห์ — ต้องเปิดแท็บนี้ค้างไว้ถึงจะทำงาน (ดูหัวข้อข้อควรระวัง)
เครื่องมือ
จุดคุ้มทุน (คำนวณ CPA ที่คุ้มทุนต่อสินค้า), ตรวจระบบ, การตั้งค่า Token/API Key ทั้งหมด

เลือก Performance Goal ให้ถูกตอนสร้างแคมเปญ

ในขั้นตอนที่ 2 ของ Wizard ถ้าธุรกิจขายผ่านแชท ให้เลือก Performance Goal เป็น "ข้อความ (Messenger/IG/WhatsApp)" — ระบบจะโชว์ตัวเลือก ปลายทางข้อความ เพิ่มมาให้เลือก Messenger/WhatsApp/อัตโนมัติ และล็อก CTA ให้ถูกต้องเอง ไม่ต้องกรอกลิงก์เว็บไซต์ก็สร้างได้ ถ้าสินค้าไม่มีเว็บไซต์

ฟีเจอร์เสริม (ไม่บังคับ)

ใช้ได้เลยโดยไม่ต้องเปิดของพวกนี้ แต่ถ้าอยากได้ฟีเจอร์ AI ครบต้องตั้งเพิ่ม

Anthropic API Key

ขับเคลื่อนฟีเจอร์ AI เกือบทั้งหมดในแอป (คำแนะนำ, วิเคราะห์, เขียนก็อปปี้) สมัครที่ console.anthropic.com เติมเครดิตขั้นต่ำ ~180 บาท ใช้ได้หลายร้อยครั้ง

OpenAI API Key

สำหรับ Gen รูปโฆษณาแบบภาพถ่ายจริงใน AI Ad Creator ถ้าไม่ตั้งค่า ระบบจะวาดรูปแบบกราฟิกให้แทนอัตโนมัติ ไม่มีก็ใช้แอปได้ปกติ

LINE แจ้งเตือน

ให้ระบบส่งแจ้งเตือนเข้า LINE เวลากฎอัตโนมัติทำงาน ต้องสร้าง LINE Bot + Cloudflare Worker แยกต่างหาก (มีคู่มือละเอียดในแอป) เหมาะกับคนที่ใช้จริงจัง

หลายบัญชีโฆษณา

ถ้าดูแลหลายบัญชี ใช้การ์ด "หลายบัญชีโฆษณา" ในหน้า Token กด "ดึงรายชื่อบัญชีทั้งหมดจาก Token ด้านล่าง" เพื่อเพิ่มทีเดียวหลายบัญชี ไม่ต้องตั้งทีละอัน

ข้อควรระวัง — อ่านก่อนเริ่มใช้งานจริง

3 เรื่องที่ควรรู้ไว้ก่อน จะได้ไม่งงทีหลัง

1 · อัตโนมัติทำงานเฉพาะตอนเปิดแท็บค้างไว้

Knock Ads เป็นเว็บไฟล์เดียว ไม่มีเซิร์ฟเวอร์เบื้องหลัง ฟีเจอร์ "ปิดโฆษณาอัตโนมัติ", "ตรวจตามเวลา" และ "รายงานรายสัปดาห์" เช็คทุก 1 นาที เฉพาะตอนที่เปิดหน้านี้ค้างอยู่ในเบราว์เซอร์เท่านั้น ปิดแท็บ ปิดคอม หรือคอมหลับ ระบบจะไม่ทำงานให้ — ถ้าต้องการอัตโนมัติจริงแบบ 24 ชม. ต้องตั้ง LINE Worker แยกต่างหาก (ดูหัวข้อฟีเจอร์เสริม)

2 · Token และ API Key เป็นของส่วนตัว ห้ามแชร์

Token ที่วางในแอปมีสิทธิ์แก้ไข/หยุดโฆษณาและใช้เงินในบัญชีได้จริง เก็บอยู่ในเบราว์เซอร์ของคุณเท่านั้น ไม่ผ่านเซิร์ฟเวอร์ของใคร — อย่าแชร์สกรีนช็อตหน้า Token หรือบอก Token ให้คนอื่นเด็ดขาด และถ้าใช้คอมสาธารณะ ให้กด "ลบออกจากเครื่อง" ทุกครั้งก่อนลุกจากเครื่อง

3 · ใช้ลิงก์เดียวกับคนอื่นได้ ไม่ชนกัน

ข้อดีคือ localStorage แยกตามเบราว์เซอร์ของแต่ละเครื่อง ต่อให้คนอื่นเปิดลิงก์ knockads.github.io เดียวกัน ข้อมูล Token/บัญชีของคุณจะไม่ไปปนกับใคร ใช้ลิงก์เดียวกันได้สบายใจ ไม่ต้องมีไฟล์แยกของใครโดยเฉพาะ

ปัญหาที่พบบ่อย

รวมปัญหาจริงที่เจอบ่อยระหว่างตั้งค่า เผื่อคุณเจอแบบเดียวกัน

ทำไมต้อง Publish ตั้งแต่ข้อ 2 เลย ไม่รอให้จบก่อนได้ไหม

รอได้ ไม่บังคับว่าต้องทำตอนไหน แต่แนะนำให้ทำเลยตั้งแต่ข้อ 2 เพราะเป็นขั้นที่เร็วที่สุดและไม่ต้องพึ่งขั้นตอนอื่นก่อน — ถ้าข้ามไปก่อน: แอปโหมด Development ยังใช้งานได้ทันทีถ้าเพจ/บัญชีโฆษณาอยู่ใน Business Portfolio เดียวกับแอป แต่โควต้าเรียก API จะต่ำกว่ามาก และถ้าเป็นบัญชีของลูกค้าที่แค่แชร์สิทธิ์มาให้ โหมด Development จะใช้งานไม่ได้เลย ต้อง Publish เป็น Live เท่านั้น — ทำเลยตั้งแต่ต้นจะได้ไม่ต้องมาห่วงเรื่องนี้อีก

เชื่อมแอปกับเพจ/บัญชีโฆษณา/พอร์ตโฟลิโอ ต้องทำตรงไหน

ไปที่ Business Settings → บัญชี → แอป (Apps) → เพิ่ม → เชื่อมต่อรหัสแอป → วาง App ID แล้วเข้าไปกำหนดคนที่มีสิทธิ์เข้าถึงแอป (รายละเอียดเต็มอยู่ในขั้นตอนที่ 4 ของหัวข้อ "ขั้นตอนติดตั้ง") ขั้นนี้แยกจากการมอบหมาย System User เข้าเพจ/บัญชีโฆษณาในขั้นตอนที่ 5 ต้องทำให้ครบทั้งสองส่วน

ตรวจระบบขึ้น "ไม่พบเพจ" ทั้งที่ติ๊ก permission ครบแล้ว

สาเหตุเกือบทุกครั้งคือติ๊ก pages_read_engagement แต่ลืม pages_show_list ซึ่งเป็นตัวที่ Meta ใช้จริงสำหรับดึงรายชื่อเพจที่บริหารอยู่ ไปที่ Graph API Explorer หรือหน้า System User แล้วติ๊ก pages_show_list เพิ่ม สร้าง Token ใหม่แล้วลองอีกครั้ง

ขึ้น error "ต้องมีสิทธิ์บทบาทผู้ลงโฆษณาหรือสูงกว่า"

เกิดกับ Token แบบ System User — permission scope ครบ แต่ System User ยังไม่ถูก "มอบหมาย" ให้เข้าถึงบัญชีโฆษณานั้นจริง ๆ ไปที่ Business Settings → บัญชี → บัญชีโฆษณา → เลือกบัญชี → มอบหมายคน → เลือก System User → ให้สิทธิ์ Admin หรือ Advertiser

สร้างแคมเปญแบบ "ข้อความ" แล้ว แต่ใน Ads Manager ของ Meta ขึ้น Conversion location เป็น Website

ปัญหานี้เกิดจากระบบเดิมไม่ได้ส่งค่าปลายทางที่ชัดเจนไปให้ Meta — แก้ไขในแอปแล้ว ตอนนี้เลือก Performance Goal เป็น "ข้อความ" จะมี dropdown "ปลายทางข้อความ" ให้เลือกเพิ่มเสมอ ถ้ายังเจอปัญหานี้กับแคมเปญที่สร้างไว้ก่อนหน้า ต้องลบ Ad Set เดิมแล้วสร้างใหม่ผ่าน Wizard เวอร์ชันล่าสุด แก้ของเก่าที่สร้างไปแล้วไม่ได้

SMS ยืนยันตัวตนจาก Meta Developer ไม่เข้าเบอร์เลย

เป็นปัญหาฝั่ง Meta ที่พบได้บ่อยกับเบอร์ไทยบางเครือข่าย ลองสลับไปยืนยันด้วยแอป Authenticator (ถ้า Meta เสนอตัวเลือกนี้) หรือรอสัก 15-30 นาทีแล้วขอส่งใหม่ อย่ากดขอรัวเร็วเกินไปเพราะ Meta จะบล็อกชั่วคราว

ทำไมเว็บอัปเดตให้เองทั้งที่ยังไม่ได้แก้อะไร

Knock Ads โฮสต์อยู่บน GitHub Pages ซึ่งจะดึงโค้ดล่าสุดจากที่เก็บ GitHub มาให้อัตโนมัติทุกครั้งที่มีการอัปเดตไฟล์ต้นทาง ไม่ต้องทำอะไรฝั่งผู้ใช้ แค่รีเฟรชหน้าเว็บก็จะเห็นเวอร์ชันใหม่

ต้องการให้ยิงแอดแบบส่งข้อความแทนเข้าเว็บไซต์ ต้องตั้งยังไงในฝั่ง Meta

เลือก Conversion location เป็น "App, website, messaging apps or calls" แล้วเลือกปลายทางเป็น Messenger/Instagram/WhatsApp — ถ้าสร้างผ่าน Wizard ของ Knock Ads ให้เลือก Performance Goal เป็น "ข้อความ" ระบบจะตั้งค่าฝั่ง Meta ให้ถูกต้องอัตโนมัติ

ข้อจำกัดที่ควรรู้

ไม่กระทบการใช้งานวันแรก แต่รู้ไว้จะได้ไม่แปลกใจทีหลัง

ระดับเรื่องรายละเอียด
กลาง ยังไม่มีปุ่ม Export CSV/PDF ที่จัดหน้าสวย ตอนนี้ "ส่งออกรายงาน" ทำได้แค่ผ่าน print ของเบราว์เซอร์ ถ้าต้องส่งรายงานให้ลูกค้าบ่อย ๆ ใช้วิธี print เป็น PDF ไปพลางก่อนได้
ต่ำ ไม่มีระบบบัญชีผู้ใช้แยกทีม เหมาะกับใช้คนเดียวต่อเครื่อง ถ้าอยากให้หลายคนดูข้อมูลชุดเดียวกันพร้อมกันแบบเรียลไทม์ ยังทำไม่ได้ในตอนนี้
ต่ำ รับมือ API ล่ม/เน็ตหลุดกลางทางยังไม่แข็งแรงมาก ถ้า Meta ตอบช้าหรือเน็ตสะดุดระหว่างทำรายการหลายรายการพร้อมกัน (เช่น ปิดโฆษณาทีละหลายตัว) บางรายการอาจไม่สำเร็จโดยไม่มีการลองใหม่อัตโนมัติ ควรเช็คผลลัพธ์ในแอปหลังรันคำสั่งใหญ่เสมอ
