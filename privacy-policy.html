🥊 นโยบายความเป็นส่วนตัว — Knock Ads

จัดทำโดย Knock Out • ปรับปรุงล่าสุด: สิงหาคม 2569
สรุปสั้นๆ: Knock Ads เป็นเครื่องมือที่ทำงาน "ในเครื่องของคุณ" ทั้งหมด ไม่มีเซิร์ฟเวอร์กลางของ Knock Out เก็บข้อมูลของคุณเลย — Token, Account ID และ API Key ทุกตัวถูกเก็บไว้ใน localStorage ของเบราว์เซอร์บนอุปกรณ์ที่คุณใช้งานเท่านั้น

1. ข้อมูลที่เก็บและเก็บไว้ที่ไหน

Knock Ads เก็บข้อมูลต่อไปนี้ไว้ใน localStorage ของเบราว์เซอร์ (ในเครื่องคุณเท่านั้น):

  • Meta Access Token และ Ad Account ID
  • Anthropic API Key และ OpenAI API Key (ถ้าใส่ไว้)
  • การตั้งค่า LINE แจ้งเตือน (ถ้าใส่ไว้)
  • ประวัติการใช้งาน/รายงาน/กฎอัตโนมัติที่คุณสร้างในแอป

ข้อมูลเหล่านี้ ไม่ถูกส่งไปเก็บที่เซิร์ฟเวอร์ของ Knock Out หรือบุคคลที่สามใดๆ เพราะแอปนี้ไม่มีเซิร์ฟเวอร์ backend — เป็นไฟล์ที่ทำงานอยู่ในเบราว์เซอร์ของคุณล้วนๆ

2. ใครเข้าถึงข้อมูลนี้ได้บ้าง

เฉพาะคุณเท่านั้น บนอุปกรณ์ที่คุณเปิดใช้งานแอป ถ้าคุณล้างข้อมูลเบราว์เซอร์ (Clear browsing data) หรือกดปุ่ม "ลบออกจากเครื่อง" ในแอป ข้อมูลจะถูกลบทันที และ Knock Out ไม่มีสำเนาเก็บไว้ที่อื่น

3. การเชื่อมต่อกับบริการภายนอก

เมื่อคุณใช้งานแอป เบราว์เซอร์ของคุณจะเชื่อมต่อ "โดยตรง" (ไม่ผ่าน Knock Out) ไปยัง:

  • Meta Graph API (graph.facebook.com) — เพื่อดึง/จัดการข้อมูลโฆษณาของบัญชีที่คุณเชื่อมต่อเอง
  • Anthropic API — เฉพาะถ้าคุณใส่ Anthropic Key เพื่อใช้ฟีเจอร์ AI แนะนำ
  • OpenAI API — เฉพาะถ้าคุณใส่ OpenAI Key เพื่อใช้ฟีเจอร์ Gen รูปภาพ

การใช้งานบริการเหล่านี้อยู่ภายใต้นโยบายความเป็นส่วนตัวของแต่ละเจ้าของบริการนั้นๆ (Meta, Anthropic, OpenAI) แยกต่างหากจากนโยบายนี้

4. คุกกี้และการติดตาม

Knock Ads ไม่ใช้คุกกี้ ไม่มีระบบวิเคราะห์พฤติกรรมผู้ใช้ (analytics) และไม่มีการติดตามผู้ใช้ข้ามเว็บไซต์แต่อย่างใด

5. การลบข้อมูล

ดูวิธีลบข้อมูลของคุณทั้งหมดได้ที่หน้า คำแนะนำการลบข้อมูล
