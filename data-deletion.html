🥊 คำแนะนำการลบข้อมูล — Knock Ads

จัดทำโดย Knock Out • ปรับปรุงล่าสุด: สิงหาคม 2569
Knock Ads ไม่มีเซิร์ฟเวอร์กลางที่เก็บข้อมูลของคุณ — ข้อมูลทั้งหมด (Token, Account ID, API Key ต่างๆ) อยู่ใน localStorage ของเบราว์เซอร์บนอุปกรณ์ของคุณเองเท่านั้น ดังนั้นการ "ลบข้อมูล" ทำได้เองทันทีโดยไม่ต้องรอ Knock Out ดำเนินการให้

วิธีที่ 1 — ลบผ่านตัวแอป (แนะนำ)

  1. เปิด Knock Ads → ไปที่เมนู เครื่องมือ → 🔑 Token
  2. ในการ์ด META ACCESS TOKEN กดปุ่ม 🗑 ลบออกจากเครื่อง
  3. ถ้ามีหลายบัญชีที่บันทึกไว้ (Multi-Account) กดปุ่ม ✕ ข้างแต่ละบัญชีในการ์ด "หลายบัญชีโฆษณา" เพื่อลบทีละบัญชี

วิธีที่ 2 — ลบข้อมูลเบราว์เซอร์ทั้งหมด

ล้าง Site Data / Local Storage ของหน้าเว็บนี้ในเบราว์เซอร์ของคุณ:

  • Chrome: ตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → ล้างข้อมูลการท่องเว็บ → เลือกเว็บไซต์นี้ → ลบ
  • Safari: การตั้งค่า → ความเป็นส่วนตัว → จัดการข้อมูลเว็บไซต์ → ค้นหาเว็บไซต์นี้ → ลบ

วิธีที่ 3 — เพิกถอนสิทธิ์การเชื่อมต่อ Facebook (ถ้าเคยเชื่อมต่อผ่านปุ่ม Facebook Login)

ไปที่บัญชี Facebook ของคุณ → การตั้งค่าและความเป็นส่วนตัว → การตั้งค่า → แอปและเว็บไซต์ → ค้นหา "KnockAds" → ลบ (Remove) การเชื่อมต่อทั้งหมดจากจุดนี้
